# ClassRealm Admin Demonstration Script

## Demo account

- **Username:** `admin`
- **Password:** `admin123`
- **Role:** Administrator

## Opening

1. Start ClassRealm and remain on the login screen.
2. Select the Admin demo quick-login option, or enter the credentials above.
3. Click **Login** and wait for the Admin Dashboard.
4. Introduce the screen as the system-level view for monitoring teacher accounts and institution-wide statistics.

## Demonstration flow

### 1. Institutional overview

1. Point out the dashboard summary cards and the **Institutional Overview** heading.
2. Explain that this view provides a quick status check of the school system.
3. Show the **Pending Teacher Onboarding** section and its request count/badge when available.

### 2. Teacher management

1. Open **Teacher Management** from the sidebar.
2. Show the teacher accounts directory and the status filter for **All**, **Active**, or **Pending**.
3. Open the create-teacher action and point out that an administrator can create an active teacher account.
4. Return to the directory and demonstrate the available account action, such as deactivation, without deleting the account.

### 3. Pending approvals

1. Open **Pending Approvals**.
2. Select a pending teacher request.
3. Explain that the administrator can review the teacher's name, email, and department/section.
4. Demonstrate **Approve** or **Reject**, then show the confirmation dialog.

### 4. System statistics and profile

1. Open **System Statistics** and briefly describe the available analytics cards/charts.
2. Open **Admin Profile** and show the administrator name, email, and system-wide access level.
3. Open **Settings** to show the simulated email-notification and maintenance-mode controls.

## Closing

1. Return to the dashboard.
2. Select **Logout** from the sidebar.
3. Confirm that the app returns to the login screen.

## Expected result

The audience should see that the Admin role manages teacher onboarding, teacher account status, system statistics, administrator information, and system settings without entering teacher or learner workflows.
