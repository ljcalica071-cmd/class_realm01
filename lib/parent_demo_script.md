# ClassRealm Parent Demonstration Script

## Demo account

- **Username:** `parent`
- **Password:** `parent123`
- **Role:** Parent/Guardian

## Opening

1. From the login screen, select the Parent demo quick-login option, or enter the credentials above.
2. Click **Login** and wait for the Parent Home screen.
3. Introduce the screen as a monitoring portal for the linked student's academic progress and school information.

## Demonstration flow

### 1. Linked student overview

1. Point out the linked student's name, section, and current academic summary.
2. Explain that the parent account is connected to the student's records and does not expose teacher or administrator controls.
3. Show the summary cards for attendance, grades, and recent academic activity.

### 2. Student schedule and teacher contact

1. Open **Student's Schedule**.
2. Show the student's subject, room, day, and class time.
3. Open **Teacher Contact**.
4. Show the teacher information available to the parent for school communication.

### 3. Attendance and academic progress

1. Open the attendance/progress area.
2. Show attendance records and explain how the parent can monitor the learner's participation.
3. Open the grades or performance area.
4. Point out the grading breakdown: **Examinations (30%)**, **Written Works (20%)**, and **Performance Task (50%)**.
5. Explain that this view is for monitoring and does not allow the parent to edit grades.

### 4. Recent updates and profile

1. Show recent notices or academic updates displayed on the parent home screen.
2. Open the linked-student/profile section.
3. Point out the available student and contact information.

## Closing

1. Return to the Parent Home screen.
2. Select **Logout**.
3. Confirm that the app returns to the login screen.

## Expected result

The audience should see that the Parent role provides a focused monitoring view of the linked student's schedule, teacher contact, attendance, academic performance, and grading breakdown.
